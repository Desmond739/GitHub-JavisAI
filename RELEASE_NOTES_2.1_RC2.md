# Naya 2.1 RC2

- Cloudflare R2 storage with local AES-256-GCM encryption and plan quotas.
- Temporary personal-number MoMo payments with transaction-reference submission,
  administrator verification and 30-day activation. No automatic activation.
- Authenticated Windows-to-Android LAN pairing with a random device token.
- Android Studio project using `cm.nexora.naya`.
- Daily explainable personal suggestion task.
- Expired subscriptions automatically return to Naya Core.
- Google authorization reduced to the selected Calendar, Gmail and Drive services.
- Naya/Zira voice behavior preserved without hardware testing.

No private credentials, phone numbers, OAuth tokens, pairing tokens, encryption
keys or signing keys are included in the release archives.
