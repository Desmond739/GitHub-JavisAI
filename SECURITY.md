# Security policy

Report vulnerabilities privately to the repository owner. Do not include
secrets or customer data in public issues.

Never commit environment files, OAuth credentials/tokens, MoMo or R2 keys, AI
provider keys, payment administrator tokens, Android keystores, customer
databases, personal memory or logs. Rotate any exposed secret.

The private beta must use HTTPS. Manual MoMo references must be checked against
the operator's transaction record before approval. Sensitive tasks remain
confirmation-gated.
