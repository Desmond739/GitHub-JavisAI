# Naya 2.0 RC1 release notes

Implemented in this release:

- Three levels: Core, Plus, Sovereign.
- 0 / 2,500 / 5,000 XAF monthly price catalog.
- 512 GB / 2 TB / 5 TB hybrid managed-capacity limits.
- Conservative included cloud allowances of 1 GB / 10 GB / 25 GB.
- MTN MoMo Collections request-to-pay and status client, fail-closed without keys.
- Google Calendar, Gmail metadata, and Drive metadata read-only connectors.
- Permissioned connector manifests for future applications.
- Wake-phrase-only privacy boundary; no ambient conversation recording.
- Persistent task queue, explicit confirmations, task worker, notifications and audit log.
- Explainable suggestion records.
- Responsive Windows/mobile PWA.
- Existing local Ollama, Whisper, and Naya/Zira voice path retained.

Activation blockers requiring owner accounts or hardware are listed in the main README.
